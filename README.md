## Selected work

### 1. [Discovering Machine Correlates of Consciousness](https://github.com/salviromain/mccviahat) 🧠

An experimental study of whether hardware traces differ when LLMs process emotionally charged versus neutral prompts. The project measures hardware performance signals during inference and tests for differences while accounting for workload and thermal confounds. In the current analysis, several power-throttle features for Llama 3.1 70B were significant after Bonferroni correction; the 7B results were not distinguishable from chance. The paper has been submitted to AGI 2026.

**Focus:** LLM systems · experimental design · statistical analysis · Linux performance counters

### 2. [Does Empathetic AI Language Cause User Attachment?](https://github.com/salviromain/llm-empathy-causal-study) 💬

A causal-inference study asking whether more empathetic chatbot responses increase users’ immediate emotional attachment. The project develops a matching strategy around prompt meaning and conversation context, and considers model differences and potential mediating mechanisms.

**Focus:** causal inference · LLM evaluation · semantic matching · research design

### 3. [Mitigating Sycophancy in LLMs](https://github.com/salviromain/RLHF_sycophancy) 🤖

An end-to-end pipeline for reducing sycophantic model behavior through supervised fine-tuning. It covers data preparation, critique and revision, LoRA fine-tuning of Llama 3 8B, benchmark evaluation, and a human preference workflow.

**Focus:** LLM fine-tuning · RLHF · LoRA · automated and human evaluation

### 4. [Speaker Age Estimation](https://github.com/salviromain/Age-Estimation-Regression) 🎙️

A predictive modeling project estimating a speaker’s age from data. The project placed in the top two out of 200 students in the course leaderboard.

**Focus:** regression · feature engineering · predictive modeling

### 5. [Spectral Clustering](https://github.com/salviromain/Spectral-Clustering) 🔎

An interactive MATLAB application comparing clustering methods across high-dimensional, nonlinear datasets.

**Focus:** unsupervised learning · spectral methods · MATLAB · computational algebra
